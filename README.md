# Credit Risk Analysis System

## Project Overview
The Credit Risk Analysis System is a beginner-friendly data science project that analyzes loan application data and explores factors related to credit risk.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Streamlit
- Jupyter Notebook

## Project Features
- Loan dataset analysis
- Data exploration and visualization
- Logistic Regression model training
- Model evaluation
- Interactive Streamlit dashboard
- Preliminary applicant risk assessment

## Project Files
- `app.py` — Streamlit dashboard
- `loan_data.csv` — Loan application dataset
- `Credit_Risk_Analysis.ipynb` — Notebook containing analysis and model training
- `credit_risk_model.pkl` — Saved machine learning model
- `credit_risk_analysis_results.csv` — Analysis results

## How to Run
Install the required libraries:

```bash
pip install pandas numpy matplotlib scikit-learn streamlit
```

Run the dashboard:

```bash
python -m streamlit run app.py
```

## Disclaimer
This is an educational project. Its dataset is synthetic, and the dashboard's applicant result is a preliminary rule-based assessment, not a validated loan approval prediction.
